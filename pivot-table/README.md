# Syncfusion Pivot Table

## Overview

Syncfusion Pivot Table is an interactive data analysis component designed to summarize and explore large volumes of structured data. This sample uses a React Pivot Table with server-side JSON data to analyze product sales by production year.

The Pivot Table provides an interactive way to rearrange fields, sort values, review sales summaries, and export the analyzed data for reporting.

## Key Features

### Data Binding
- Local and remote data binding
- Server-side data processing
- JSON data support
- REST API integration

### Data Analysis
- Row, column, and value field configuration
- Product ID row field and production year column field
- Units sold and sold amount value fields
- Sorting and summary values
- Currency formatting for sold amounts

### Performance
- Virtual scrolling for large result sets
- Optimized rendering for data-intensive reports
- Server-side processing to reduce client-side workload

### User Experience
- Interactive Field List
- Grouping Bar for direct field arrangement
- Rearrangeable rows, columns, and values
- Responsive layout support
- Keyboard accessibility

### Advanced Capabilities
- Pivot field configuration
- Aggregated value presentation
- Server-side pivot engine support
- Custom toolbar actions

### Exporting

## Getting Started

1. Install the project dependencies.
2. Start the Vite development server.
3. Configure the remote JSON endpoint for the Pivot Table.
4. Arrange row, column, and value fields using the Field List or Grouping Bar.
5. Export the summarized pivot view to Excel when required.

```bash
npm install
npm run dev
```

The sample is built with React, TypeScript, Vite, and `@syncfusion/ej2-react-pivotview`. It loads data from the remote endpoint configured in `src/App.tsx`.
